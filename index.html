1 Abstract

The Free Code Syndicate — Software as Right, not Privilege: Free as in Freedom.

We're a community of people who write, read, break, and study code together, in public. No paywalled knowledge, no gatekept repositories — if you're willing to learn, you're already in.

This page works like the rest of what we do: it's source you can read, fork, and send a pull request against. Sections 2 and 3 below are pulled straight from our GitHub organization and our own project data — nobody has to hand-edit a slide deck to keep this current.
